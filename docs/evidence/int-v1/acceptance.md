## Measurements (host loopback, Debug, headless, synthetic: not device figures)

Workload: sender = real `EditorSession` with 3 remote objects (crate, tree, foliage) on a flat world, receiver = the real preview
child process, assets already cached on both sides (no download in the timed region), one paired writer, loopback WebSocket,
Godot 4.7.2 headless on Apple silicon, no other load besides the AssetStudio server. Times are measured on the sender clock only
(no clock subtraction).

| Metric | n | p50 | p95 | max | Spec target |
|---|---|---|---|---|---|
| Commit: sender commit to receiver `commit_ack` observed by the sender | 200 | 19.0 ms | 20.3 ms | 39.8 ms | p95 <= 500 ms: **met on host** |
| Provisional (surrogate): `ping`/`pong` round trip while a provisional stroke streams at about 15 updates/s (289 previews sent in 18 strokes) | 240 | 6 ms | 9 ms | 9 ms | p95 <= 250 ms for provisional ACKs. **Not directly measurable**: protocol v1 has no provisional acknowledgement (D4). The surrogate bounds the receiver main-loop round trip only |

Commit samples are quantised by the sender's frame loop (about one 60 Hz frame). A first run of the same test measured p50 19.2,
p95 20.3, max 21.5 ms (commit) and p50 7, p95 9 (surrogate), so the values are repeatable at this resolution. Release-build
iPad-over-Wi-Fi performance and the 15 Hz stroke on device are NOT RUN.
