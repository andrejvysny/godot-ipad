# Editor icons

- `tool_select.svg`, `tool_place.svg`, `tool_sculpt.svg`, `tool_paint.svg`, `tool_path.svg`: copies of
  `picker_checked`, `multimesh`, `height_add`, `texture_paint`, `navigation` from Terrain3D 1.0.2
  (`app/addons/terrain_3d/icons/`), MIT, see `app/addons/terrain_3d/LICENSE.txt`. Fill/stroke colours were changed to white so
  the UI can tint them (accent when active).
- All other icons (undo, redo, chevrons, switches, dot): authored in this repository, CC0.
- `swap.svg`, `minus.svg`, `plus.svg`, `close.svg`, `check.svg` (Invert, inspector steppers, clear/remove, ticks): authored in this
  repository, CC0, white strokes so the UI can tint them.
- Mode and tool icons of Editor v2 are used straight from `res://addons/terrain_3d/icons/` (height_add, height_flat, height_mul,
  texture_paint, texture_spray, color_paint, picker_checked, multimesh, holes, layers, navigation, autoshader), untinted like the design.
